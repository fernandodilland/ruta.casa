# Política de seguridad

ruta.casa es un sitio estático (HTML, CSS y JavaScript que corren en tu
navegador): no hay servidor propio, cuentas ni base de datos, así que la
superficie de riesgo es mínima.

Aun así, si encuentras algo que pueda afectar a quien visita el sitio
(por ejemplo, un problema en una dependencia incluida como
`lib/three.min.js`, o en la configuración de despliegue):

1. **No lo publiques en un issue abierto.**
2. Repórtalo en privado con la función de GitHub
   **Security → Report a vulnerability** de este repositorio
   (*Private vulnerability reporting*), o abre un issue pidiendo un
   contacto privado sin dar detalles del problema.

Revisaremos el reporte lo antes posible y te daremos crédito si así lo
quieres. ¡Gracias!
